Los dos temas

Cada tema tiene una página de entrada y dos diagramas: arquitectura y flujo de trabajo.

db-ai · datos sin SQL

Una CLI agent-first que da acceso a bases SQLite mediante rutas: alias, tablas, filas y campos. Sin SQL libre, con permisos, ETag, transacciones y una única salida JSON.

  • Qué hace y cómo se opera
  • Arquitectura de db-ai
  • Flujo de trabajo

ACM · memoria de continuidad

Una aplicación de referencia construida sobre db-ai: sesiones, hallazgos, decisiones, checkpoints y preferencias en SQLite por proyecto, bajo el alias mem. Sin motor propio, MCP ni LLM.

Cómo se lee este sitio

Páginas estáticas, sin servidor ni recursos externos. Los diagramas son artefactos verificados, no imágenes sueltas.

Estático y autónomo

HTML, CSS y JavaScript locales. No se descargan tipografías, librerías ni fuentes externas; si Inter o JetBrains Mono no están instaladas, el navegador usa su pila del sistema.

Diagramas con recibo

Cada arquitectura.html y flujo-de-trabajo.html se genera desde su .json con Archify. El .delivery.json acompaña al HTML y registra que la especificación y el artefacto son los mismos.

Tema claro y oscuro

El tema se resuelve antes de pintar con data-theme en <html> y se conserva en localStorage. La preferencia del sistema es el valor inicial.
